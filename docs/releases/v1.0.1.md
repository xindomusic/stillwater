# Stillwater 1.0.1

A visual refinement update for clearer fish, more natural bubbles, and a living background.

- **Fixed fish ghosting:** turns now use one solid fish view with geometric deformation, instead of overlapping two photographs. The image correspondence is precomputed; no image analysis runs while the wallpaper is playing.
- **More natural bubbles:** clear centers, directional highlights, subtle refraction, smooth detachment, and faster rise for larger bubbles. Sources still change over time.
- **Moving plants and water:** vegetation-aware sway, rippling surface water, and slowly drifting light on the riverbed. Use **Motion & light → Plant sway / Water movement** to adjust them.
- Existing preferences, feeding, day/night lighting, and Still mode are preserved.

Download the DMG or ZIP below. Quit the previous Stillwater instance before replacing the app in Applications.

Requires Apple Silicon and macOS 14+. This app is ad-hoc signed, **not Apple-notarized**. See the [installation guide](https://github.com/xindomusic/stillwater/blob/main/docs/INSTALL.md) for first launch and checksum instructions.

Model tests and native shader checks cover fish double exposures, bubble continuity, independent plant/water controls, zero-intensity behavior, and Still freezing. See [validation](https://github.com/xindomusic/stillwater/blob/main/VALIDATION.md) for native app results and remaining limitations.
